# Bossgee School Manager

A full-stack school management web application that helps administrators, teachers, and staff manage students, classes, attendance, and roles efficiently.

## 🚀 Features

- **Student Management:** Add, update, and view student information.
- **Class Management:** Create classes and assign teachers.
- **Attendance Tracking:** Mark daily attendance for students.
- **User Roles:** Assign roles such as admin, teacher, and student.
- **Dashboard:** View key statistics like total students, classes, and attendance.
- **File Uploads:** Upload student profile pictures.

## 🛠️ Technology Stack

- **Frontend:** React, TypeScript, Vite, TailwindCSS
- **Backend:** Node.js, Express
- **Database:** MySQL
- **Validation:** Zod
- **API Structure:** RESTful APIs
- **Version Control:** Git & GitHub
